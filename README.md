# Bolo - learn Urdu

A Duolingo-style web app for learning Urdu: bite-sized lessons, hearts, XP, quests and a leaderboard.
Built on the open-source [Lingo / duolingo-clone](https://github.com/sanidhyy/duolingo-clone) by Sanidhya Kumar Verma (MIT licence, see [LICENSE](LICENSE)).

---

## Coming back after a break? Start here

### Everyday commands

Run these from the `Bolo_WIP` folder:

| I want to… | Command |
|---|---|
| Start the app (then open http://localhost:3000) | `npm run dev` |
| Stop the app | press `Ctrl + C` in that terminal |
| Load or refresh the lessons in the database (**resets progress**) | `npm run db:prod` |
| Update the database tables after changing `db/schema.ts` | `npm run db:push` |
| See which audio and images are still missing | `npm run assets:report` |
| Generate missing audio with AI voices (needs Azure key in `.env`) | `npm run audio:generate` |
| See learners and who has Pro | `npm run pro -- list` |
| Give an account free Pro (unlimited hearts), no payment | `npm run pro -- grant <name or user id>` |
| Remove free Pro | `npm run pro -- revoke <name or user id>` |
| Browse the database in a web UI | `npm run db:studio` |
| Check for code errors | `npx tsc --noEmit` and `npm run lint` |

### How the pieces fit

```
curriculum JSON  ──(npm run db:prod)──▶  Neon Postgres  ──▶  Next.js app  ──▶  browser
  urdu_curriculum.json   (Stage 1)        courses/units/       /learn  /lesson
  curriculum/*.json      (Stage 2+)       lessons/challenges
```

- **Lessons are written as JSON**, not in the database directly. `npm run db:prod` reads them, generates the quiz questions and fills the database.
- **Clerk** handles sign-in. **Neon** is the hosted Postgres database. **Stripe** (optional) powers the "unlimited hearts" upgrade.
- Your keys live in `.env`, which is never committed. `.env.example` lists the variables you need.

### Where things live

| Folder / file | What's in it |
|---|---|
| `curriculum/stage-0.json` | Start Here: beginner lessons (speaking first, then the alphabet) |
| `curriculum/stage-2.json` | Stage 2 lessons (clean format; copy it to start Stage 3) |
| `urdu_curriculum.json` | Stage 1 lessons (older, mixed formats; still supported) |
| `scripts/curriculum/load.ts` | Reads every curriculum format into one shape |
| `scripts/curriculum/build.ts` | Turns lessons into questions; finds the audio and images for each |
| `scripts/prod.ts` | The seed script (`npm run db:prod`) |
| `scripts/assets-report.ts` | Writes the missing-asset checklists into `docs/assets/` |
| `public/sound/` | Urdu audio recordings (`.mp3`) |
| `public/images/` | Lesson pictures (`.svg`). Older letter and person pictures are in `public/` directly |
| `app/lesson/` | The lesson / quiz screen |
| `app/(main)/learn/` | The lesson path screen |
| `db/schema.ts` | Database tables |
| `docs/` | Guides: lesson plans, recording guide, asset to-do lists |

### Common tasks

**Add or edit a lesson**
1. Edit `curriculum/stage-2.json` (each lesson has `vocab`, `phrases`, `dialogue` and `quiz`; copy an existing lesson as a template).
2. Run `npm run db:prod`.
3. Run `npm run assets:report` to see what audio and pictures the new content needs.

**Add audio:** follow [docs/RECORDING_GUIDE.md](docs/RECORDING_GUIDE.md). In short: save the `.mp3` under `public/sound/` with the name from [docs/assets/audio-todo.md](docs/assets/audio-todo.md), then run `npm run db:prod`.

**Add a picture:** save a square SVG in `public/images/` and reference it from the lesson with `"image": "/images/name.svg"`, then run `npm run db:prod`.

**Become an admin** (to use `/admin`): sign in once, copy your user ID from the Clerk dashboard (Users → your user → `user_…`), put it in `CLERK_ADMIN_IDS` in `.env`, and restart `npm run dev`.

### Troubleshooting

| Symptom | Likely fix |
|---|---|
| Every page errors about Clerk | The Clerk keys in `.env` are missing or wrong |
| `/learn` is empty, or sends you to `/courses` | Pick the Urdu course; if there's none, run `npm run db:prod` |
| Database errors mentioning a missing column | Run `npm run db:push` |
| A sound doesn't play | See section 5 of the recording guide |
| Changes to `.env` aren't picked up | Restart `npm run dev` |
